# Baatein — Social frontend starter

A responsive Instagram-inspired social application interface built with React, Vite, React Router and plain CSS.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (normally http://localhost:5173).

## Included screens

- Home feed with story strip, post cards, likes, save and comment input interactions
- Explore grid
- Reels placeholder
- Messages inbox preview
- Profile page
- Search page
- Notifications page
- Create-post UI
- Login and signup UI
- Responsive mobile navigation

## Important

This is the frontend stage. The authentication forms are visual only, posts and accounts use sample data, and messages are not yet connected to a server. The next stage is to build the Express/MongoDB API, authentication, uploads and Socket.IO private messaging.
